# Konlyut: Конвертер валют

[English README](README.md)

Konlyut — нативный Android-конвертер на Kotlin, Jetpack Compose и Material 3. В приложении нет рекламы, аккаунтов, подписок и аналитики. Идентификатор пакета `com.maxim.currency` сохранён для совместимых обновлений без потери данных.

## Возможности

- Пересчёт выбранных валют с изменением порядка списка. Результаты показываются максимум с двумя знаками после запятой, вычисления сохраняют более высокую точность.
- Работа с последними сохранёнными курсами без интернета, отображение времени их обновления. Источник — публичный API ExchangeRate-API.
- Конвертация выделенного, отправленного или вставленного текста с распознаванием русских и английских названий валют.
- Создание, редактирование, импорт, экспорт и обмен пользовательскими цветовыми темами. Встроенные темы не изменяются.
- Автоматическая проверка стабильных GitHub Releases не чаще раза в сутки при открытом приложении либо ручная проверка. Установка APK всегда требует подтверждения пользователя.

Поддерживаются **русский и английский** языки, Android 8.0 (API 26) и новее.

## Установка

После публикации проекта скачайте подписанный APK из GitHub Releases и откройте его на телефоне. Первый файл будет называться `Konlyut-v1.0.0.apk`. Публичного релиза пока нет.

Локальный Debug APK после сборки находится в `app/build/outputs/apk/debug/app-debug.apk`. Подписи Debug и Release различаются, поэтому Release не установится поверх Debug. Перед удалением Debug откройте **Настройки → Перенос настроек → Сохранить настройки**. После установки Release загрузите файл: вернутся валюты, суммы, предпочтения и темы. Курсы загрузятся заново.

## Обновления

Адрес репозитория задаётся при сборке: `konlyut.updateRepository=OWNER/Konlyut-Currency-Converter`. Владелец пока неизвестен, поэтому в текущем проекте адрес пуст. Приложение не отправляет запросы на произвольный адрес; ручная проверка сообщает, что источник не настроен. Токен GitHub не используется.

Приложение проверяет последний стабильный релиз, ожидает файл `Konlyut-vVERSION.apk` и контрольную сумму SHA-256 из метаданных GitHub. Перед вызовом установщика проверяются размер и сумма файла, пакет, повышение `versionCode`, версия и подпись. Скачивание можно отменить, обновление — отложить. Постоянного фонового сервиса нет.

Настройка подписанных выпусков описана в [инструкции по релизам](docs/RELEASING.md); для ввода пароля в скрытом локальном запросе подготовлен `scripts/build-release.ps1`. Реальное обновление между двумя подписанными APK ещё требует опубликованного релиза и проверки на устройстве.

## Сборка из исходного кода

Установите JDK 21 и Android SDK с платформой 37 и build tools 36.0.0. Задайте `JAVA_HOME`, `ANDROID_HOME` или создайте `local.properties` с `sdk.dir`. Gradle Wrapper включён в проект.

```powershell
cd D:\CurrencyConverter
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

Используются Android Gradle Plugin 9.5.2, Kotlin 2.4.21 и Gradle Wrapper 9.6.0. Локальные инструменты этого компьютера описаны в [инструкции разработчика](docs/DEVELOPMENT.md). Пароли и ключи подписи в исходном коде отсутствуют.

## Основные файлы

- `app/src/main/java/com/maxim/currency/ui/` — экраны Compose и редактор тем.
- `app/src/main/java/com/maxim/currency/domain/` — расчёты и модели тем.
- `app/src/main/java/com/maxim/currency/data/` — курсы, настройки, файлы тем и обновления.
- `app/src/main/res/` — локализация, ресурсы и FileProvider.
- `app/src/test/` — автоматические JVM и Robolectric тесты.
