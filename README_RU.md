## Что такое Konlyut?

**Konlyut** — бесплатный конвертер валют для Android без рекламы, аккаунтов и подписок.

Приложение позволяет быстро пересчитывать суммы сразу в нескольких валютах. Можно самостоятельно выбрать нужные валюты, изменить их порядок и вводить сумму в любой из них — остальные значения пересчитаются автоматически.

Курсы обновляются через интернет, а если подключения нет, используются последние сохранённые данные.

Также можно конвертировать суммы прямо из выделенного текста в других приложениях и полностью настраивать цвета интерфейса с возможностью делиться собственными темами.

## Возможности

- **Мгновенная конвертация.** Пересчёт всех выбранных валют при вводе суммы.
- **Свой список валют.** Добавление, удаление и изменение порядка.
- **Работа без интернета.** Использование последних сохранённых курсов.
- **Конвертация текста.** Распознавание сумм, обозначений и названий валют.
- **Настройка внешнего вида.** Светлая, тёмная и пользовательские цветовые темы.
- **Обмен темами.** Импорт и экспорт оформления через файлы.
- **Два языка.** Русский и английский.
- **Обновления через GitHub.** Автоматическая или ручная проверка новых версий.

## Установка

Приложению нужен Android 8.0 или новее. Для установки откройте [GitHub Releases](https://github.com/qFumipon/Konlyut-Currency-Converter/releases), скачайте APK из последнего стабильного выпуска и подтвердите установку на устройстве. Локальная Debug-сборка создаётся в `app/build/outputs/apk/debug/app-debug.apk`.

## Обновления

Приложение настроено на репозиторий `qFumipon/Konlyut-Currency-Converter`. В настройках можно выбрать автоматическую проверку при открытии приложения (не чаще раза в сутки) или только ручную проверку. Установка всегда подтверждается пользователем в Android.

Проверка использует публичные стабильные GitHub Releases; токен в приложение не встроен. Реальная установка обновления между разными версиями ещё требует проверки на телефоне. Подробности — в [инструкции по релизам](docs/RELEASING.md).

## Сборка из исходного кода

Нужны JDK 21 и Android SDK с платформой 37 и build tools 36.0.0. Задайте `JAVA_HOME` и `ANDROID_HOME` либо создайте локальный `local.properties` с `sdk.dir`. Gradle Wrapper включён в проект.

```powershell
cd D:\CurrencyConverter
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

Проект использует Kotlin, Jetpack Compose и Material 3. `applicationId` — `com.maxim.currency`; версия первого выпуска — `1.0.0` (`versionCode` 8). Ключ Release-подписи и пароли в репозиторий не входят. Инструкции для разработчика и сборки подписанного APK находятся в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) и [docs/RELEASING.md](docs/RELEASING.md).
